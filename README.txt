قالب الموقع الأولي للمركز الحضاري الطبي

محتويات الحزمة:
- index.html: واجهة الموقع المتجاوبة.
- data/site.json: بيانات المركز وأرقام التواصل.
- data/services.json: قائمة العيادات والخدمات.
- .pages.yml: إعداد لوحة Pages CMS.
- assets/: مكان الشعار والصور.

ملاحظة:
ارفع الشعار إلى مجلد assets باسم hadari-logo.png.
ارفع جميع محتويات المجلد إلى جذر مستودع GitHub hadari-medical-website.
لوحة الإدارة: https://app.pagescms.org بعد تسجيل الدخول بحساب GitHub وتثبيت تطبيق Pages CMS على المستودع.
